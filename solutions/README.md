# Completed solutions

As requested, this directory is included in the student repository.

| Directory | Reference |
|---|---|
| `activity-1/` | Reusable role helper and consistent web/API use |
| `exercise-1/` | Protected GET and PATCH routes |
| `exercise-2/` | Repaired operation, ownership and property checks |
| `exercise-3/` | Safe errors and structured logs |
| `exercise-4/` | Headers and rate limiting |

Try the task, make a prediction, then use the relevant solution to diagnose a difficulty. Explain any code you use and add your own negative test. Each solution runs on its own. At repository root, `python tools/check_all.py solutions` runs each solution's suite in a separate process. Do not run one pytest collection across the whole repository: the teaching applications deliberately reuse module names.
